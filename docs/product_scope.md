# 历史时间对照 Agent 产品边界

## 产品定位

历史时间对照 Agent 是一个面向历史学习、研究、内容创作和知识整理的智能体系统。它通过结构化历史事件库和 Agent 分析能力，帮助用户按时间点、时间段、国家、地区、文明、主题横向比较历史事件，并解释事件之间可能存在的关联。

一句话定义：

> 输入一个时间点、时间段、国家、事件或主题，系统输出同一时期不同国家和地区发生了什么，并给出横向对照、背景解释、关联分析和来源依据。

## 目标用户

| 用户类型 | 典型需求 |
|---|---|
| 历史学习者 | 查询某一年世界各地发生了什么，形成整体历史视野 |
| 教师和课程设计者 | 生成横向时间线、课堂讲义、对照表 |
| 内容创作者 | 为视频、文章、播客查找同一时期的世界背景 |
| 研究型用户 | 比较不同文明、政权、宗教、战争、贸易之间的关系 |
| 产品内部运营者 | 导入、校对、维护历史事件数据 |

## 核心业务场景

| 场景 | 用户问题示例 | 期望输出 |
|---|---|---|
| 按年份横向对照 | 755 年中国发生安史之乱时，欧洲、中东、日本在发生什么？ | 按国家/地区列出同期事件，并解释背景 |
| 按时间段比较 | 对比 1400-1600 年中国、欧洲、奥斯曼帝国和日本的发展 | 分阶段表格、主题比较、关键趋势 |
| 事件同期背景 | 蒙古西征期间，世界其他地区发生了什么？ | 事件详情、同期事件、扩散影响 |
| 关联分析 | 蒙古帝国扩张和欧洲贸易变化有什么关系？ | 直接关联、间接关联、证据、争议点 |
| 主题时间线 | 生成 600-900 年欧亚大陆宗教传播时间线 | 多地区时间轴、关键节点、来源 |
| 教学资料生成 | 给我做一张 8 世纪世界历史对照表 | 可复制表格、摘要、讲解提纲 |

## 第一版 MVP 范围

第一版不追求覆盖全世界所有历史，而是先证明“时间对照 + 事件检索 + Agent 解释”这条链路可用。

| 项目 | 第一版范围 |
|---|---|
| 时间范围 | 公元 600-900 年 |
| 地区范围 | 中国、阿拉伯帝国、拜占庭、法兰克王国、印度、日本、中亚 |
| 事件数量 | 200-500 条结构化事件 |
| 事件类型 | 政治、战争、王朝更替、宗教、贸易、科技文化 |
| 查询方式 | 年份查询、时间段查询、事件详情、同期事件、地区比较 |
| 输出形式 | 对照表、简要分析、来源列表 |
| Agent 自主等级 | L2/L3：低风险查询自动执行，数据导入和修改需要确认 |

## 不做范围

第一版暂不做：

| 不做项 | 原因 |
|---|---|
| 覆盖全部历史时期 | 数据规模过大，容易影响质量 |
| 自动爬取并直接入库 | 历史数据需要来源校验和人工确认 |
| 多智能体协作 | 单智能体加确定性工具更稳定 |
| 复杂知识图谱推理 | 先用结构化字段和关系表验证价值 |
| 自动判断历史争议结论 | 争议内容需要显示来源和置信度 |
| 直接给出无来源结论 | 历史产品必须可追溯 |

## 成功指标

| 指标 | 第一版目标 |
|---|---|
| 年份查询成功率 | 90% 以上能返回相关事件 |
| 时间段查询可读性 | 能按地区和年份生成清晰表格 |
| 来源覆盖率 | 核心事件至少有 1 个来源 |
| 关联分析可靠性 | 明确区分事实、推断和争议 |
| 平均响应时间 | 普通查询 5 秒内返回首段结果 |
| 数据可维护性 | 运营者可以导入、校对、更新事件 |
